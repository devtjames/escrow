# ESCROW PAYMENT LOGIC

Students can deposit multiple times until:

```php
$current_balance >= $target_amount
```

When target is reached:

* wallet locks
* deposit button disables
* further deposits blocked
* status changes to completed

---

# STRICT DEPOSIT LOGIC

```php
if ($wallet['status'] !== 'active') {
    return "Deposit locked";
}

$remaining = $wallet['target_amount'] - $wallet['current_balance'];

$amount = min($amount, $remaining);

$newBalance = $wallet['current_balance'] + $amount;

if ($newBalance >= $wallet['target_amount']) {
    $status = 'completed';
}
```
